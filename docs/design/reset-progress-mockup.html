창 길이는 추정한다

퍼센트를 내려면 창이 몇 시간짜리인지 알아야 하는데 API 는 창 길이를 안 준다. 리셋 시각만 온다. 그래서 종류로 정한다.

창길이근거
5시간5시간이름 그대로. 첫 사용에서 5시간 뒤 리셋
주간 전체7일리셋이 매주 같은 요일 같은 시각이다 (금요일 오전 6:00)
주간 Fable7일위와 같다

추정이라는 점은 밝혀 둔다. 서버가 창 길이를 바꾸면 이 숫자만 틀리고 남은 시간은 그대로 맞는다. 리셋 시각이 없는 창(아직 안 열린 창)은 퍼센트도 안 붙인다. 시각이 지났으면 100% 다.
