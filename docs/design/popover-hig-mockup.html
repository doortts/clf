  1. 1. 빨강의 의미 충돌 (Color). 이 화면에서 빨강은 소진이다. 기본 계정 이름의 흰 글자 + 빨간 상자는 강조가 아니라 위험 신호로 읽힌다. 악센트 파란 점으로 바꾼다. 메뉴바의 포커스 밑줄과 같은 색 언어라 "파랑 = 위치, 등급색 = 상태" 가 앱 전체에서 일관된다.
  2. 2. 상태와 동작을 가른다 (Buttons). HIG 는 단추 라벨을 동사로 쓰라고 한다. "창 실행중" 은 상태인데 누르면 동작이 일어나서, 설명 툴팁까지 달아야 했다. 상태는 노란 점 배지(실행중)로 이름 옆에 두고, 단추는 동사(앞으로 꺼내기)로 바꾼다. 툴팁 없이도 읽힌다.
  3. 3. 시스템 컨트롤로 (Consistency). 직접 그린 상자 단추는 hover, 눌림, 키보드 포커스 링이 없다. 시스템 bordered 계열로 바꾸면 공짜로 생긴다. 모서리 반지름도 3, 4, 5pt 가 섞여 있어서 한 단계(6pt 근처)로 통일한다.
  4. 4. 글자 크기 바닥은 10pt (Typography). 9pt 가 여덟 곳이다. macOS 에서 10pt 아래 본문은 권장되지 않는다. 푸터 시각과 설정 캡션을 10pt 로 올리고 계층을 13 / 12 / 11 / 10 네 단으로 고정한다.
  5. 5. 세그먼트에 라벨을 (Forms). 설정 세그먼트 세 줄이 라벨 없이 쌓여 있어 무엇을 고르는지 기억에 의존한다. 왼쪽에 좁은 라벨 열(막대, 자세히, 기준)을 붙인다.
  6. 6. 배지 대비 (Accessibility). 14% 틴트 위 10pt 컬러 글자는 대비 3:1 아래로 떨어진다. 배경을 한 단 올리고 글자를 밝힌다.

게이지 자체의 입체감(바깥 알약 명도)은 별도 시안 gauge-depth-mockup.html 에서 진행 중이라 여기서는 다루지 않았다.
