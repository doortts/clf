  1. 파란 점은 뺀다. 점과 배지가 같은 말을 두 번 하고, 점을 남기면 8pt 와 간격 8pt 를 이름에서 빼앗는다. 메뉴바의 파란 밑줄은 그대로라 `파랑 = 위치` 언어는 거기서 유지된다.
  2. 회색이라 종류 배지와 안 싸운다. `team` 은 악센트 22% 채움이고 `기본` 은 라벨색 20% 채움이다. 둘이 나란히 서도 경계가 보이고, 회색이 뒤로 물러나서 이름과 게이지가 먼저 읽힌다. 별도 창의 노란 점과도 갈린다.
  3. 1안은 여유가 4.4pt 뿐이다. `NAVER_TEAM_52` 는 들어가지만 한 글자만 길어지면 잘린다. 네 번째 카드가 16자 이름으로 그 자리를 보여준다.
  4. 2안은 단추에서 `앞으로` 를 뺀다. 34.5pt 가 돌아와 배지 값을 덮고 17자까지 버틴다. 배지가 창을 말하고 단추가 동작을 말하는 자리라 `꺼내기` 만으로 읽힌다. 두 카드가 같은 라벨을 쓴다.
