자동 재개 시안

리밋 소진으로 멈춘 CLI 세션을 창이 리셋되고 3분 뒤에 자동으로 이어 돌린다. 실행 직전에 사용량을 다시 읽어 5시간과 주간 전체 둘 다 잔여 5% 이상일 때만 돌린다. 5% 는 알림이 빨강을 예고하는 그 경계다. 설계는 docs/design/16-auto-resume.md.

설정 패널에는 넣지 않는다. 켜면 계정과 세션과 프롬프트가 아래로 열려 패널이 길어지고, 그 패널은 이미 화면 하나를 다 쓴다. 세션을 다루는 창이 이미 있으므로 거기에 탭으로 넣는다.

1. 들어가는 자리: 팝오버 단추 이름을 고친다

전

⇆세션 작업 이전

후

⇆세션 작업 이전/재개

단추는 그대로 하나다. 창 안에서 탭으로 갈린다. 팝오버에 단추를 하나 더 두면 설정 패널을 늘리지 않으려 한 이유가 무의미해진다.

고르는 것이 곧 켜는 것이다. 꺼 둔 채로 고르면 아무 일도 안 일어나서 누른 것이 먹었는지 알 수 없다. 세션을 고르면 위 체크가 같이 켜진다. 놓을 때는 끄지 않는다. 다른 세션으로 갈아타는 중일 수 있다.

3. 상태 상자 여섯 가지

창 아래 상자 하나가 단계를 말한다. 왼쪽 색 띠는 이전 탭의 안내 상자와 같은 어휘다. 초록은 평상, 노랑은 기다림, 빨강은 문제.

5시간, 주간 창을 지켜보는 중입니다. 소진되면 리셋 3분 뒤에 이 세션을 이어 돌립니다.
한도가 소진됐습니다. 2시간 14분 뒤에 재개합니다. 그때 잔여를 다시 확인합니다.
재개를 실행하는 중입니다.
5분 전에 이어 돌렸습니다. 다시 지켜보는 중입니다.
주간 전체 잔여가 3% 라 이번 리셋에는 재개하지 않았습니다. 다음 리셋에 다시 확인합니다.
재개하지 못했습니다. claude 가 exit 1 로 끝났습니다. No conversation found with session ID

보류와 실패는 둘 다 빨강이지만 뜻이 다르다. 보류는 규칙대로 안 돈 것이고 실패는 돌리려다 깨진 것이다. 문구가 그 차이를 말한다. 보류에는 다음에 다시 본다는 말을 붙이고, 실패에는 exit code 와 stderr 첫 줄을 그대로 적는다.

예약 상자에 그때 잔여를 다시 확인합니다 를 붙인다. 시각만 적으면 그 시각에 무조건 돈다고 읽힌다.

시각은 상대값으로 적는다. 주간 리셋은 며칠 뒤라 오후 2:32 만 적으면 오늘로 읽힌다. 남은 시간 표기는 막대가 쓰는 것을 그대로 쓴다.

3-2. CLI 로그인 한 줄

실행되는 계정은 이쪽이다. 위에서 고르는 것은 한도를 지켜볼 계정일 뿐이라, 이 줄이 없으면 다른 계정 한도로 도는 것을 알 길이 없다. 실패가 아니라서 알림도 안 뜬다.

CLI 로그인: NAVER_TEAM_52. 지켜볼 계정과 같습니다
CLI 로그인: NAVER_TEAM_52. 지켜볼 계정 NAVER_TEAM_40 와 달라서 NAVER_TEAM_52 의 한도로 돕니다
CLI 가 로그인돼 있지 않습니다. 터미널에서 claude auth login 을 먼저 하세요
CLI 로그인 계정을 확인하는 중입니다
CLI 로그인 계정을 확인하지 못했습니다. claude 가 exit 1 로 끝났습니다

같을 때도 말한다. 조용히 있으면 확인을 한 것인지 못 한 것인지 구분이 안 된다. 확인 중은 색을 안 쓴다. 아직 아무 소식도 아니다.

막지는 않는다. 로그인이 없거나 계정이 달라도 켜고 끌 수 있다. 우리가 아는 것은 방금 물어본 순간의 상태뿐이고 실제로 도는 것은 몇 시간 뒤다. 그 사이에 사용자가 로그인할 수 있다.

자격증명 파일을 직접 읽지 않는다. 형식이 바뀌면 조용히 틀린 답을 하게 되고, 우리가 읽을 이유가 없는 것을 읽게 된다. CLI 가 자기 상태를 답하는 문을 쓴다.

켜기는 열어 둔다. 목록이 비는 것은 고장이 아니라 상태다. 고를 것이 없으면 저장되는 것도 없으므로 상태는 꺼진 것이다. 켜기만 눌러 둔 상태를 저장하지 않는다. 무엇을 돌릴지 없는 예약이 남는다.

5. 알림

결과만 알린다. 예약은 알리지 않는다. 소진 알림이 이미 갔고 예약은 창 안 상태에 있다. 창을 닫아 두고 지내는 기능이라 결과는 알림으로 와야 한다.

이어 돌렸을 때

세션 자동 재개지금 Build 스크립트 작성 세션을 이어서 실행했습니다

본문에 세션 이름을 넣는다. 어느 작업이 다시 돌기 시작했는지가 전부다.

보류했을 때

자동 재개 보류지금 주간 전체 잔여가 3% 라 이번 리셋에는 재개하지 않았습니다

왜 안 돌았는지를 말한다. 조용히 건너뛰면 고장으로 보인다.

실패했을 때

자동 재개 실패지금 claude 가 exit 1 로 끝났습니다. No conversation found with...

exit code 와 stderr 첫 줄. 짐작을 덧붙이지 않는다.

7. 두 탭이 보는 세션은 출처가 다르다

무엇인가데스크톱 앱의 대화 레코드CLI 의 세션 기록

같은 창에 있어도 섞지 않는다. 자동 재개는 CLI 로 돌리므로 CLI 가 아는 세션만 이어 돌릴 수 있다. 목록을 합치면 못 돌리는 세션을 고를 수 있게 된다.

세션 하나만 고른다. 여러 세션 동시 재개는 필요하다는 말이 나오면 그때 늘린다. 주간 Fable 창은 안 본다. 모델 하나에만 걸리는 창이라 재개를 막을 이유가 못 된다. 잔여 기준은 5% 고정. 노브는 조절하고 싶다는 말이 나올 때 단다. 실행 단추는 없다. 지금 당장 돌리고 싶으면 터미널에서 claude --continue 를 치면 된다. 이 창은 자동으로 돌 조건을 정하는 자리다.
