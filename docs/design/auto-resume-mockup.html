자동 재개 시안

리밋 소진으로 멈춘 CLI 세션을 창이 리셋되고 3분 뒤에 자동으로 이어 돌린다. 실행 전에 5시간과 주간 전체 창의 잔여를 다시 읽어 둘 다 30% 이상일 때만 돌린다. 30% 는 게이지가 초록으로 바뀌는 그 경계다. 설계는 docs/design/16-auto-resume.md.

1. 설정 구획

기존 설정 패널 맨 아래, 알림 칸 다음에 한 구획을 더한다. 켜면 계정, 세션, 프롬프트 세 줄이 아래로 열린다.

켠 상태

자동 재개
✓리밋 풀리면 세션 자동 재개
리셋 3분 뒤, 5시간과 주간 잔여가 30% 이상일 때만 돕니다
계정 NAVER_TEAM_52↕
CLI 가 이 계정으로 로그인돼 있어야 합니다
세션 clf, Build 스크립트 작성↕
프롬프트 이어서 진행해줘
5시간, 주간 창을 지켜보는 중

세션 메뉴는 프로젝트, 세션 제목 꼴로 최근 10개를 보여준다. 상태 줄은 지금 단계를 항상 말한다. 조용히 도는 기능은 도는지 안 도는지가 제일 궁금하다.

끄면 계정, 세션, 프롬프트 줄이 접힌다. 안 쓰는 기능이 자리를 먹지 않는다.

2. 상태 줄

구획 아래 한 줄이 단계를 따라 바뀐다. 색점은 메뉴바 게이지와 같은 어휘다: 초록은 평상, 노랑은 기다림, 빨강은 문제.

단계표시언제
대기 ● 5시간, 주간 창을 지켜보는 중 소진된 창이 없다
예약 ● 5시간 창 소진. 오후 2:32 재개 예정 소진 감지. 리셋 + 3분에 타이머
실행 ● 재개 실행 중... 점검 통과, CLI 가 도는 중
실행 후 ● 오후 2:32 재개함. 다시 지켜보는 중 마지막 결과를 남기고 대기로
보류 ● 주간 잔여 12%. 여유가 없어 재개 안 함 점검에서 30% 미만
실패 ● 재개 실패 (exit 1). 세션이 없습니다 CLI 가 비정상 종료

3. 알림

결과만 알린다. 예약은 알리지 않는다. 소진 알림이 이미 갔고, 예약 사실은 설정의 상태 줄에 있다.

재개했을 때

세션 자동 재개지금 clf, Build 스크립트 작성 세션을 이어서 실행했습니다

본문에 세션 이름을 넣는다. 어느 작업이 다시 돌기 시작했는지가 알림의 전부다.

보류했을 때

자동 재개 보류지금 주간 전체 잔여 12% 라 이번 리셋에는 재개하지 않습니다

왜 안 돌았는지를 말한다. 조용히 건너뛰면 고장으로 보인다.

실패했을 때

자동 재개 실패지금 claude 가 exit 1 로 끝났습니다. No conversation found...

exit code 와 stderr 첫 줄. 짐작을 덧붙이지 않는다.

4. 흐름

대기고른 계정의 5시간,
주간 창을 지켜본다 --> 예약소진 감지.
리셋 + 3분에 타이머 --> 점검사용량을 다시 읽어
두 창 잔여 30% 이상? --> 실행claude --resume ID -p
결과를 알림으로

점검에서 떨어지면 보류하고 대기로 돌아간다. 같은 리셋 시각으로는 두 번 예약하지 않는다. 토글이 켜져 있는 한 다음 소진에서 다시 돈다.

세션 하나만 고른다. 여러 세션 동시 재개는 필요하다는 말이 나오면 그때 늘린다. 주간 Fable 창은 안 본다. 모델 하나에만 걸리는 창이라 재개를 막을 이유가 못 된다. 여유 기준은 30% 고정. 노브는 조절하고 싶다는 말이 나올 때 단다.
